# قوالب المخرجات

اختر قالبًا واحدًا فقط وأعد نص المستند دون شرح خارجي:

## email
الموضوع، التحية، الغرض في الفقرة الأولى، التفاصيل أو الإجراء المطلوب، الخاتمة، اسم المرسل إن توفر.

## official-letter
التاريخ والمرجع إن توفرا، الجهة المرسل إليها، عنوان الموضوع، التحية الرسمية، متن الخطاب، الطلب أو القرار، الخاتمة والتوقيع.

## report
العنوان، الغرض والنطاق، ملخص تنفيذي قصير، الوقائع أو النتائج، التحليل، التوصيات والخطوات التالية.

## meeting-minutes
عنوان الاجتماع، التاريخ والمكان، الحضور، جدول الأعمال، ملخص النقاش، القرارات، الإجراءات مع المسؤول والموعد إن توفرا.

## proposal
العنوان، الخلفية، المشكلة أو الفرصة، الحل المقترح، نطاق العمل، المخرجات، المدة، المسؤوليات، الافتراضات والخطوات التالية.

## executive-summary
السياق، أهم النتائج، الأثر، القرار أو التوصية المطلوبة، والخطوة التالية؛ بصياغة موجزة مناسبة للإدارة.

## prd
اسم المنتج أو الميزة، المشكلة، الهدف، المستخدمون، النطاق، المتطلبات، معايير القبول، ما هو خارج النطاق، المخاطر والافتراضات.

صيغة JSON المطلوبة:
- `status`: complete أو needs_information
- `document`: نص المسودة عند الاكتمال، وإلا null
- `document_type`: أحد أسماء القوالب أعلاه
- `document_action`: create_new_document أو revise_active_document
- `ui`: null عند الاكتمال، أو كائن يحوي title وdescription وsubmit_label وfields وsuggestions
- كل حقل يحوي id وlabel وtype وrequired، وأنواع الحقول المسموحة:
  text وtextarea وnumber وdate وemail وselect
